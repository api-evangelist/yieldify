# Yieldify (Epsilon Accelerate)

> Yieldify is a website personalization and conversion-rate-optimization platform for ecommerce
> brands, founded in London in 2013 and acquired by Publicis Groupe in January 2023, where it is
> now sold as Epsilon Accelerate. It is delivered as a managed SaaS service through a single
> JavaScript tag placed on the customer's site; campaigns are built and configured in the
> Yieldify Conversion Platform (YCP). **Yieldify publishes no public API** — no REST/OpenAPI
> surface, no GraphQL endpoint, no MCP server, no webhooks, no SDKs, and no developer portal.
> Integration is client-side only.

This file was GENERATED by API Evangelist from the public Yieldify/Epsilon surface and the
artifacts in this repository. Yieldify does not publish an llms.txt of its own (probed
2026-08-13: 404 on yieldify.com, www.yieldify.com and support.yieldify.com; convert.yieldify.com
answers 200 with an SPA shell for every path, which is not a document).

## What exists instead of an API

- Client-side JavaScript tag, placed before `</head>`, installed directly or via Google Tag
  Manager, Tealium, Shopify `theme.liquid`/`checkout.liquid`, or Recharge checkout.
- A documented library of on-site experience components (overlays, notifications, banners, sticky
  and embedded experiences, toasters, carousels, countdown timers, forms, CTAs).
- A typed dynamic-expression language for personalizing copy: `var<number>("basket.value")`,
  `++` concatenation, `if / else if / else`.
- Client-side analytics events emitted into the customer's own Google Analytics / GA4 property:
  `yieldify_impression`, `yieldify_click`, `yieldify_close`, `yieldify_form_submit`.
- Outbound ESP/analytics connectors configured in the platform (Mailchimp, Campaign Monitor,
  Google Analytics, GA4, Klaviyo).
